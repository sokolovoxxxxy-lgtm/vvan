# VVAN — барбершоп в Санкт-Петербурге

Одностраничный сайт барбершопа: вёрстка по дизайн-макету (1440 px), полностью адаптивный,
со слайдером, якорной навигацией и рабочей формой онлайн-записи.

Стек: чистые **HTML + CSS + JavaScript**, без сборщиков и зависимостей.
Шрифты (Inter, Unbounded) лежат локально в `fonts/` — CDN не нужен, всё работает офлайн.

---

## Структура

```
vvan/
├── index.html              # вся разметка (8 секций)
├── favicon.svg
├── assets/
│   ├── css/styles.css      # дизайн-система + все секции + адаптив
│   ├── css/fonts.css       # локальные @font-face (Inter, Unbounded)
│   └── js/app.js           # слайдер, меню, селекты, календарь, валидация, отправка
├── public/images/          # фото (сейчас — ч/б заглушки)
├── fonts/                  # 12 woff2, локальные шрифты
├── server.cs               # нативный dev-сервер (C#) — основной
├── vvan-server.exe         # его сборка (не в git, см. .gitignore)
├── server.ps1              # тот же сервер на PowerShell — запасной
├── .env.example            # переменные для Telegram-уведомлений
└── shots/                  # скриншоты для приёмки
```

## Запуск локально

Основной способ — **нативный exe** (PowerShell-процессы в этой среде убивают через 2–5 минут,
этот — нет):

```powershell
cd "C:\Users\User\Desktop\сбор в кейс\vvan"

# сборка (нужна только при изменении server.cs):
& "C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:winexe `
  /optimize+ /out:vvan-server.exe /r:System.Web.Extensions.dll server.cs

# запуск:
.\vvan-server.exe 8080
```

Запасной вариант с той же функциональностью и логами:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -Port 8080
```

Открыть <http://localhost:8080>

**Логи** (папка `logs/`, не попадает в git):

| Файл | Что внутри |
|---|---|
| `server-console.log` | диагностика: баннер, `[fatal]`, `[error]`, `[booking]` |
| `server-heartbeat.log` | метка времени каждые 60 с; обрезается при старте. **Если меток нет — процесс убили** |
| `booking-YYYY-MM-DD.log` | заявки из формы |
| `server.pid` | PID текущего сервера (`Stop-Process -Id (Get-Content logs\server.pid)`) |

Форма записи отправляет `POST /api/booking`; ответ пишется в `logs/booking-YYYY-MM-DD.log`.
Если API недоступно (например, файлы открыты напрямую через `file://`), форма переходит
в демо-режим и показывает сообщение об успехе без отправки.

### Уведомления в Telegram (опционально)

Скопируйте `.env.example` в `.env` и заполните:

```
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=123456789
```

## Изображения

Все картинки лежат в `public/images/`. Сейчас это **ч/б заглушки** тех же пропорций —
замените их реальными фото, сохранив имена:

| Файл | Секция | Размер / пропорции |
|---|---|---|
| `hero-1.jpg` | Слайдер, 1-й кадр — **фото интерьера VVAN** | 2560×1429 (≈1.79:1) |
| `hero-2.jpg` | Слайдер, 2-й кадр — **фото моек и кресел VVAN** | 2560×1429 (≈1.79:1) |
| `hero-3.jpg` … `hero-5.jpg` | Слайдер на первом экране (заглушки) | 1600×734 (≈2.18:1) |
| `master-irina.jpg` | Карточка мастера «Ирина» | 1312×1100 (≈1.19:1) |
| `master-ekaterina.jpg` | Карточка мастера «Екатерина» | 1312×1100 (≈1.19:1) |
| `tools.jpg` | Фон в блоке онлайн-записи | 1000×1050 (≈0.95:1) |

Фотографии должны быть **чёрно-белыми** (стиль макета): конвертируйте до загрузки
или оставьте как есть — на сайтах они и так отображаются через `filter: grayscale(1)`.
