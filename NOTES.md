## 2. Что за проект

Одностраничный сайт барбершопа VVAN, собранный **вручную по дизайн-макету** (скриншоту) —
чистые HTML/CSS/JS, без Node/npm/Python/сборщиков. Цель — публикация в соцсетях.

**8 секций:** sticky-хедер → hero-слайдер (5 фото, fade; **переключение вручную: клик по фото на десктопе, свайп влево→следующий / вправо→предыдущий на телефоне**, автопрокрутки и счётчика `01—05` больше нет) →
`01 О НАС` → `02 УСЛУГИ И ЦЕНЫ` (hover + предвыбор) → `03 КОМАНДА` (2 карточки, предвыбор мастера) →
`04 КОНТАКТЫ` → `#booking` (форма, кастомные селекты, 14 дней, слоты 10:00–21:00, валидация,
`POST /api/booking`) → футер с огромным VVAN.

## 9. Окружение и лайфхаки (Windows, PowerShell 5.1)

- **Нет** Node/npm/Python; есть `winget`, `git` 2.55, `gh` 2.102, headless Edge.
- **PS-скрипты с кириллицей требуют UTF-8 BOM** — файлы из `write` нужно пересохранять: `[IO.File]::WriteAllText($p, [IO.File]::ReadAllText($p,[Text.UTF8Encoding]::new($false)), [Text.UTF8Encoding]::new($true))`.
- **Консоль PS режет кириллицу** — в выводе `Write-Output` будет мусор; для проверок использовать ASCII-метки или коды символов (`[char]0x0418...`).
- **Скриншоты**: `msedge.exe --headless=new --hide-scrollbars --force-device-scale-factor=1 --user-data-dir=<свежий> --virtual-time-budget=8000 --window-size=1440,6000 --screenshot=...`. Обрезка хвоста по фону из последнего пикселя. **Свежий профиль обязателен** — иначе картинки из кэша.
- **`browser.screenshot` не работает** (снимает рабочий стол) — только headless Edge.
- **`read` для картинок** — возвращает иногда закэшированный файл, читать по одной.
- Имя макета в Downloads содержит не-ASCII — выбирать `Get-ChildItem "$env:USERPROFILE\Downloads" -Filter "VVAN*.png"`.
- Замена в строках PS: `"$i:"` внутри кавычек = ошибка парсера (`InvalidVariableReferenceWithDrive`) → использовать `("...{0}..." -f $i)`.
- `Invoke-WebRequest` в PS5.1 декодирует UTF-8 как Latin-1 → для проверки меты: `[Text.Encoding]::UTF8.GetString($r.RawContentStream.ToArray())`.
